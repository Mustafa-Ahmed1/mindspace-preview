FoundationsColours

Colours

Theme colours change with the mode. Fixed colours are the same in both. The landing universe stays dark.

Roles

Surfaces--ms-bg --ms-panel --ms-raise --ms-sunken --ms-pop

For page, cards, raised parts, wells, menus. Never for text.

Lines--ms-line --ms-line-strong

For dividers, borders, table rules. Never for fills.

Text--ms-text --ms-mute --ms-dim --ms-done

For primary, secondary, tertiary, finished or disabled. Never for anything under 4.5:1 on its surface.

Accent (space colour)--ms-accent --ms-tint --ms-sel-line

For primary button, selection, focus, the open tab. Never for status, charts, large fills.

Status--ms-ok-text --ms-warn-text --ms-bad-text

For status tags, field errors, deltas. Never for buttons (except danger), decoration.

AI--ms-ah --ms-ah-text

For anything Auto or an Autohuman made or said. Never for human content.

Text on the space colour

Buttons and selections put text on the space colour; it needs 4.5:1. In light mode the colour is first darkened until white text on it reaches 4.5:1; apps and the workspace use the same rule.

Buttons

Buttons start actions. Pick the kind by how important the action is, the size by where it sits. One primary per view.

Which button

KindUse it forRules
PrimaryThe one main action of a view: Save, Create invoice, Send for approval.One per view, at the end of its header or footer. Never two.
Secondarythe defaultEvery other action: Cancel, Export, Filter, Add note.Most buttons are this one. No class needed.
GhostQuiet actions in toolbars, dense rows and footers: Skip, Clear, Show more.Never the main action, never alone in a dialog.
DangerThe destructive action itself: Delete, Remove access, Cancel order.Only for the action that destroys; ask first or offer undo (Actions pattern).
Icon buttonWell-known, repeated actions: search, more ⋯, close, edit, pin.Always an aria-label and a tooltip. Rare or risky actions get a label instead.
SendSending a message or a prompt.Only in a composer; disabled until there is something to send.

Every state

Hover, pressed and focus are frozen here so you can compare them. Focus appears for keyboard users only.

Disabled or hidden?

Hide an action the person’s role can never do. Disable one that becomes possible later, and say why: hover the button below. Never disable Save because of form errors: let them press it and show the errors.

Loading

Done in under 300 ms: no indicator. Up to about 5 s: the button spins and can’t be pressed again; the rest of the page stays usable. Longer: run it in the background, show a toast, and notify when it’s done.

Icons and labels

Do

One icon, before the label. A chevron after the label only when the button opens a menu.

Don’t

Two icons, or an icon after the label that isn’t a menu chevron.

Do

A verb and what it acts on, in sentence case, three words or fewer. Say the count when there is one.

Don’t

“OK”, “Submit”, “Yes”, capitals, or a question as the label.
